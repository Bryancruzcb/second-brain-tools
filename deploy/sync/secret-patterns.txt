# What keeps a note on the desktop. One pattern per line: kind, name, regex,
# separated by whitespace. "content" patterns run on every line of a note,
# "path" patterns on its path from the vault root. Any match keeps the whole
# file home, and the report shows only the pattern name and line number.
#
# Every content pattern needs a fake sample in FAKE_SECRETS in
# deploy/sync/tests/test_sync_vault.py, or the tests fail.

# A password or key assigned a value. The value must contain a digit and must
# not start like a lookup or placeholder, so code such as
# api_key = os.environ["X"] and API_KEY=${API_KEY} stays uploadable.
content  credential-assignment  (?i)\b(?:password|passwd|pwd|api[_-]?key|secret[_-]?key|client[_-]?secret|access[_-]?token|auth[_-]?token)\b["']?\s*[:=]\s*["']?(?!(?:os\.|process\.env|getenv|env\.|<|\$|\{\{|your|xxx|\*\*\*|\.\.\.|example|placeholder|changeme|redacted))(?=[^\s"'`]*\d)[^\s"'`,;)\]]{8,}
